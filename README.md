## Newegg Responsive Redesign

This is a responsive front-end implementation of our redesigned Newegg website. We built it using plain **HTML, CSS, and JavaScript** and does not need React, a database, an API, or a build step to run.


## How to run

1. Extract the ZIP file and load the project in Visual Studio Code.
2. Install the Live Server extension by Ritwick Dey if it is not already installed.
2. Right click `index.html` and select "Open with Live server."
3. The website will open in your browser.
4. Use the navigation links in the website to move between the four pages.


## Run a local server (Optional)

If python is installed, open a terminal in the project folder and run

```bash
python -m http.server 8000
```

Then open this address in your browser `http://localhost:8000`.



## Project Files and Pages

- index.html — Homepage
- search.html — Search Results page
- product.html — Product Details page
- support.html — Support form and confirmation screen
- styles.css — Shared styling, responsive layouts, and animations
- app.js — Shared JavaScript interactions
- assets/ — Product images, logo, and promotional image
